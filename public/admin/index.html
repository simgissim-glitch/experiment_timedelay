관리자 로그인

연구자 계정으로 로그인해 주세요. 설정되지 않은 환경에서는 접근할 수 없습니다.

참여 현황

익명 ID가 발급된 참가자가 분모입니다. ID 발급 전 비동의 세션은 포함하지 않습니다. 진행 중에는 단순 미완료가 포함되며, 이탈로 자동 판정하지 않습니다.

조건별 배정·완료·행동

완료율 = 완료자 / 해당 조건 전체 배정자(적격성 종료 포함). 실제 지연은 질문 전송부터 첫 글자 표시까지 관측된 답변의 평균이며, 복원 표시·미관측 값은 제외합니다. 표본 수는 답변 수입니다.

단계별 도달과 미완료

명시적 종료 후 미완료와 아직 진행 중인 미완료를 구분합니다. 과거 이관 기록의 시각 출처는 참가자 상세에서 확인할 수 있습니다.

검색·출처 접근 통계

검색 실패도 실행 시도에 포함합니다. 출처 클릭은 실제 읽기·이해·검증을 의미하지 않습니다. 외부 출처는 앱과 다른 호스트로 분류하며 출처 간 독립성은 판정하지 않습니다.

연구 데이터 다운로드

완료자·중단자·미완료자를 포함합니다. 각 다운로드는 별도 DB 스냅샷입니다. 수집이 진행 중이면 조회·파일 사이에 데이터가 추가될 수 있으며 각 행의 snapshot_at으로 시점을 구분합니다. 빈 셀은 결측이며 0과 다릅니다.

운영 제한

이 화면에서는 데이터를 삭제하거나 실험 조건·자극물을 변경할 수 없습니다. 해당 작업은 대상 환경 확인 → 백업 → 영향 검토 → 연구자 명시적 승인 후 별도 운영 절차로 수행해야 합니다.
