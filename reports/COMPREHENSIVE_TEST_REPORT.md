# 종합 테스트 및 배포 준비 보고서

검증일: 2026-11-15 KST. 환경: Windows, Node v26.7.0, npm 11.19.0, 숨김 Chrome, 로컬 Express, 격리된 PGlite. **최종 서버 테스트 77개 + 브라우저 테스트 5개 모두 통과했습니다.** 최초 실행의 참가자 브라우저 대기 경쟁은 테스트를 보완한 뒤 PC/모바일 모두 재확인했습니다. 실제 연구 실시와 외부 공개 배포는 보류입니다.

## 범위와 실제 외부 연결

- 자동 테스트 DB는 매번 새로 생성하는 전용 PGlite입니다. 실제 연구 DB를 초기화하거나 시드 참가자를 넣지 않았습니다. 동의/사전 설문/기록 저장은 실제 SQL과 제약·권한을 실행하지만 Supabase 원격 접속 검증을 뜻하지 않습니다.
- 실제 OpenAI의 `gpt-6-luna`로 2회 연속 대화에서 예산 100만원을 유지하는 답변을 확인했고, 별도 1회 호출에서 가상 배터리 4시간×2의 잘못된 12시간 답변을 8시간으로 정정했습니다. SDK/대화 구성은 [공식 OpenAI 대화 상태 문서](https://developers.openai.com/api/docs/guides/conversation-state)와 [모델 문서](https://developers.openai.com/api/docs/models/gpt-6-luna)를 확인했습니다. 사용자가 요청한 모델을 다른 모델로 교체하지 않았습니다.
- 실제 DB 점검: `DB_NOT_CONFIGURED`(선택된 test 환경의 TEST_DATABASE_URL 없음). DATABASE_URL이 있더라도 환경을 자동으로 바꿔 접속하지 않았습니다.
- 실제 검색 점검: `SEARCH_NOT_CONFIGURED`. 자동 테스트의 검색 결과는 명시적인 테스트 대역이며 실제 자료로 제시하지 않습니다.
- 실제 관리자 DB/CSV 대조: `ADMIN_DB_NOT_CONFIGURED`. 격리된 DB와 CSV의 일치는 검증했고 실제 Supabase 대조는 미완료입니다.
- 운영 의존성 `npm audit --omit=dev --json`: 취약점 0건. 샌드박스 네트워크 오류 후 승인된 외부 네트워크로 다시 조회했습니다.
- Git 저장소가 아니므로 커밋 이력/GitHub 원격의 비밀 노출 여부는 검증하지 못했습니다. 현재 작업 트리 검사와 비공개 경로 HTTP 접근 검사는 통과했습니다. 실제 외부 배포와 GitHub 업로드는 하지 않았습니다.

무작위 표본은 단순 무작위 배정의 실제 한 번의 결과이며 1:1:1은 **확률**입니다. 정확히 80명씩 배정하거나 적은 표본의 동일 인원 수를 보장하지 않습니다. 이 표본으로 배정의 장기 확률이나 연구 결과를 추정하지 않습니다. 강제 조건 테스트는 측정 재현을 위한 주입 경로로 실제 참가자 API에는 없습니다.

## 목표와 브라우저 관측 지연

최종 `npm run test:browser` 결과입니다. 가상 시간 가속 없이 Chrome performance와 렌더링 프레임 후 표시 이벤트를 사용했습니다. 최초 답변은 공통 가상 자극물이고 후속 답변은 결정적 테스트 제공자입니다. 따라서 **실제 브라우저 표시 지연 관측값이지만 실제 OpenAI 응답 속도/배포 속도 측정값은 아닙니다.**

| 조건 | 목표 | 최초 공통 답변 | 목표 대비 | 후속 답변 | 목표 대비 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | 2,000ms | 2,044ms | +44ms | 2,026ms | +26ms |
| B | 9,000ms | 9,025ms | +25ms | 9,019ms | +19ms |
| C | 20,000ms | 20,038ms | +38ms | 20,022ms | +22ms |

생성 시간이 목표보다 긴 별도 테스트: A 목표 2,000ms, 테스트 제공자가 약 2,400ms 동안 준비, 실제 표시 2,450ms(+450ms). 시간을 줄여 기록하거나 목표로 바꾸지 않았습니다. 지연 표본은 조건당 2회로 작은 기능 검증 표본이며 분포/성공률을 일반화할 수 없습니다. 브라우저 관측 시각은 물리 디스플레이의 광학 측정이 아닙니다. 실제 배포에서는 cold start·네트워크·단말·탭 비활성화·생성 시간으로 추가 차이가 생길 수 있어 별도 파일럿이 필요합니다.

원자료: `tests/timing-results.json`, 무작위 표본: `tests/randomization-results.json`. 모두 테스트 전용 집계이며 실제 참가자 자료가 아닙니다.

## 배포 전 판정과 연구자 결정 사항

**아래 항목이 해결되기 전에는 실제 참가자를 모집하거나 공개 배포하지 않습니다.** 절차와 환경변수 표는 [DEPLOYMENT.md](../DEPLOYMENT.md)에 있습니다.

1. **연구계획·승인:** 참여 적격성 전체 기준, 표본 수/제외 기준/중도 이탈 처리, 단순 무작위 배정 유지 여부(정확한 80명씩 필요하면 설계 변경), 연구 승인 절차를 확정합니다. 현재 연구용 등록 경로는 차단되어 있습니다.
2. **동의·보관·철회:** 승인된 동의서, 담당자 연락처, 데이터 보관 기간/접근자/철회·삭제 요청 방법, 익명 ID와 쿠키 분실 시 본인 자료 확인 방법을 확정합니다. 현재 ‘참여 중단’은 자동 자료 삭제를 뜻하지 않습니다.
3. **과제·자극물:** 실제 장비/후보/사양/출처와 최초 질문·동일한 핵심 오류 하나·정확한 정정 근거·버전을 확정합니다. 현재 가상 루멘 T1은 개발용이며 연구용 파일 approved=false/TODO 차단을 유지합니다.
4. **설문·디브리핑:** 사전/사후 문항·척도·코딩값/버전·조작 의심 문항을 승인하고 타당성을 검토합니다. 실제 오류와 올바른 정보를 설명하는 디브리핑 및 철회 안내를 승인합니다. 승인 표시만 바꿔서는 문항/정책 구현이 완료되지 않습니다.
5. **지연 조작 파일럿:** 목표 대비 허용 오차, 실제 LLM 생성이 2초를 넘거나 조건 분포가 겹칠 때 처리, 탭 비활성/렌더링 지연/재접속 표본의 분석·제외 규칙과 시계 품질 규칙을 사전 결정합니다. 목표값 대신 실제 관측값을 사용해야 합니다.
6. **행동·결과 조작적 정의:** 검색 실행, 서로 다른 외부 호스트, 독립 출처, 검증 행동/활동 시간의 정의를 확정합니다. 클릭/앱 이탈을 읽기·이해로 자동 판정하지 않습니다. 오정보 수용 판정 기준/코더 교육·일치도·수정 이력 정책을 확정합니다.
7. **외부 서비스·개인정보:** 실제 OpenAI/검색 프로젝트·키·모델 버전·사용량 한도·제공자 데이터 처리 정책, 제출 문장에 개인정보를 쓰지 않도록 하는 안내/운영 정책을 확정합니다. 연구 중 검색 결과 변화와 모델 변동을 어떻게 기록/통제할지도 결정합니다.
8. **운영·배포 미완성:** 실제 Supabase 최소 권한·TLS·백업/복구 시험, 관리자 인증 설정, 실제 DB/CSV 대조, 외부 제공자 연결이 필요합니다. Vercel은 영속 공유 관리자 인증/로그인 제한, 강제 종료 작업 복구, 큰 CSV 내보내기 방식까지 보완해야 합니다.
9. **복원·접근성 범위:** 최종 제출 전 결정/사후 입력은 아직 메모리 초안입니다. 입력 중 새로고침 복원이 필요하면 서버 초안 저장을 추가합니다. 쿠키 삭제·다른 기기 재접속 복구, 실제 모바일/Safari·접근성·예상 동시접속 부하 시험도 남아 있습니다.

기존 .env와 실제 연구 데이터는 변경·삭제·초기화하지 않았습니다. 테스트 결과 파일·코드·문서를 추가/갱신했고 외부 배포는 수행하지 않았습니다.
